# CineWave

Я сделал яркий каталог фильмов и сериалов на русском языке. В этом проекте я собрал аккуратный интерфейс с поиском, фильтрами, избранным и подробной карточкой выбранного тайтла.

## Что есть в проекте

- поиск по названию, жанру и описанию;
- фильтрация по формату: фильм или сериал;
- фильтрация по жанру;
- сортировка по рейтингу, году и названию;
- блок с главным тайтлом недели;
- модальное окно с подробной информацией;
- избранное с сохранением в `localStorage`;
- полностью русскоязычный интерфейс;
- адаптивная вёрстка.

## Стек

- React
- TypeScript
- Vite
- CSS

## Как запустить

```bash
npm install
npm run dev
```

## Как собрать проект

```bash
npm run build
```

## Структура проекта

```text
src/
  components/    — UI-компоненты
  data/          — демо-данные каталога
  styles/        — глобальные стили
  types.ts       — типы данных
  App.tsx        — главная логика интерфейса
```

## Идея проекта

Я хотел сделать не просто список карточек, а приятный каталог, в котором удобно выбирать фильм или сериал по настроению. Поэтому я сделал акцент на цвете, крупных блоках, мягких градиентах и заметных отступах между элементами.
